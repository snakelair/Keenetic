## [1.0.72] - 2026-09-14

### Sync API High-Performance Compression & Collection Catalog Delivery
- **Gzip-компрессия на порту синхронизации (`internal/syncapi`)**:
  - Внедрен `gzipMiddleware` для сервиса синхронизации (порт 18089). Ответы эндпоинта `/api/v1/albums` сжаты с 2.1 МБ до ~120 КБ (в 18 раз!), а `/api/v1/folders` — с 230 КБ до ~20 КБ.
  - Полностью устранены обрывы соединений (`SSLHandshakeException: connection closed`) при прохождении через облачные KeenDNS-туннели (`netcraze.link`).
- **Кэширование дерева папок (`cachedFolderTree`)**:
  - Иерархическое дерево папок теперь строится один раз во время фоновой индексации и кэшируется в оперативной памяти роутера.
  - Запрос `/api/v1/folders` отдается за 0.001 мс без повторного обхода 85 000 фото и без нагрузки на CPU роутера.
- **Единый сжатый каталог коллекций (`/api/v1/sync/catalog` и `CompactDatabase`)**:
  - Структура `CompactDatabase` расширена полями `Albums`, `FolderTree`, `Trips`, `Places` и `Categories`.
  - Зарегистрирован быстрый эндпоинт `/api/v1/sync/catalog`, отдающий все альбомы, папки, путешествия, места и категории в одном легком Gzip-пакете (<40 КБ) за 100 мс.

## [1.0.71] - 2026-09-14

### Desktop Environment Adaptation: Windows 10/11 Default Apps & Linux MIME Visibility Filtering
- **Адаптивная видимость десктопных разделов настроек**:
  - Разделы «Системный просмотровщик фото/видео» и «Связка Desktop и роутера Keenetic» теперь отображаются **исключительно** в окружениях, поддерживающих десктопную интеграцию: **Windows 10/11 Default Apps** и **Linux Desktop MIME** (`.desktop` / `xdg-mime`), а также в приложении `SmartPhoto Desktop`.
  - На роутерах Keenetic, OpenWrt и серверах без графического интерфейса десктопные разделы автоматически скрываются, сохраняя панель управления роутером чистой и ориентированной на сетевые задачи.
  - Реализован метод `desktop.IsViewerSupported(isDesktop)` и `system.IsKeenetic()`, определяющие наличие XDG/MIME окружения, графической сессии и типа платформы.
  - Эндпоинт `GET /api/system/associations` теперь возвращает флаги `is_supported`, `system_name`, `is_desktop` и `is_keenetic`.
- **Контекстные рекомендации FFmpeg и KeenDNS**:
  - Блок с разъяснением преимуществ FFmpeg-mini («Потребление RAM в 10 раз меньше...») активируется только на роутерах Keenetic.
  - Для Desktop систем отображается специальная подсказка с рекомендациями по использованию встроенного FFmpeg-mini или системного FFmpeg с аппаратным ускорением GPU.
  - Элементы KeenDNS (проверка статуса, публикация прокси) активны только на поддерживаемых роутерах Keenetic.
- **Интеграция SmartPhoto Desktop во вкладку «Клиенты»**:
  - Во вкладку «Клиенты и интеграция со SmartPhoto» добавлена официальная карточка настольного приложения SmartPhoto Desktop для Windows, Linux и macOS с описанием технологии PowerBoost, системного просмотрщика и прямой работы с NAS.

  - В настройках веб-интерфейса селектор потоков расширен вариантами 8, 16, 24, 32 потока.
- **Связка Desktop и роутера Keenetic (UI, API проверки и пошаговые инструкции)**:
  - Добавлена карточка управления связкой в настройках с селектором режимов (Прямой доступ через SMB/сетевой диск `\\172.16.1.1\photos`, Smart-Sync REST API, Автономный режим).

  - Подробное иллюстрированное руководство, объясняющее преимущество прямого доступа через общую папку роутера (Desktop берет на себя тяжелую нагрузку на 32 потоках, а роутер отдает готовое с 0% CPU).
