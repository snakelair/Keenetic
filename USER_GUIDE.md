## 1. Введение и архитектура

**Smart-Utils** разработан как легковесный и производительный инструмент для полного контроля над роутером Keenetic через удобный браузерный интерфейс.

### Архитектурные особенности:
- **0% лишней нагрузки на CPU:** написано на Go, работает как единый бинарный сервис `/opt/bin/smart-utils`.
- **Без сторонних зависимостей:** все веб-ресурсы (HTML, CSS, JS) встроены прямо в бинарный файл.
- **Порт по умолчанию: `8090`**, что гарантирует отсутствие конфликтов со **Smart-Route** (`8088`) и **Smart-Photo** (`8089`).

---

## 2. Установка и запуск службы

### Быстрая установка через терминал роутера:
```bash
curl -sSL https://raw.githubusercontent.com/snakelair/Keenetic/main/install.sh | sh -s smart-utils
```

### Управление службой Entware:
- Запуск: `/opt/etc/init.d/S99smart-utils start`
- Остановка: `/opt/etc/init.d/S99smart-utils stop`
- Перезапуск: `/opt/etc/init.d/S99smart-utils restart`
- Проверка статуса: `/opt/etc/init.d/S99smart-utils status`

## 3. Веб-терминал

Вкладка **Веб-Терминал** предоставляет прямой интерактивный доступ к командной оболочке роутера без необходимости открытия внешнего SSH-клиента:
- **PTY-сессия:** корректная работа с интерактивными утилитами (`top`, `nano`, `vi`, `htop`).
- **Быстрые кнопки команд:** запуск `opkg update`, `free -m`, `df -h`, `ip a`, `ndmc` в один клик.
- **Поддержка буфера обмена:** вставка текста комбинацией клавиш `Ctrl+V`.

## 4. Файловый менеджер (Total Commander)

Двухпанельный файловый менеджер спроектирован по классическим принципам Total Commander / Midnight Commander:

### Горячие клавиши:
| Клавиша | Функция | Описание |
| :--- | :--- | :--- |
| **`Tab`** | Смена панели | Переключает фокус между левой и правой панелями |
| **`Enter`** | Войти / Открыть | Вход в директорию или открытие файла |
| **`Space`** | Выделить | Выделение файлов для групповых операций |
| **`F3`** | Просмотр | Быстрый просмотр текстовых файлов и конфигураций |
| **`F4`** | Правка | Полноэкранный редактор текста с подсветкой и `Ctrl+S` |
| **`F5`** | Копия | Копирование файлов в каталог второй панели |
| **`F6`** | Перенос | Перемещение или переименование файлов |
| **`F7`** | Новая папка | Создание каталога в активной панели |
| **`F8`** | Удалить | Удаление выбранных файлов с подтверждением |
| **`F9`** | Архив | Создание архива `.tar.gz` или распаковка архивов |
| **`F10`** | Атрибуты | Настройка прав доступа (`chmod 0755`, `0644`) |

## 5. Менеджер пакетов OPKG

- **Каталог фидов:** отображение всех подключенных репозиториев из `/opt/etc/opkg.conf` и `/opt/etc/opkg/*.conf`.
- **Подключение популярных репозиториев:** 1-клик подключение официального репозитория `snakelair/Keenetic` и основных зеркал Entware.
- **Живая консоль выполнения:** отображение логов команд `opkg update`, `opkg upgrade`, `opkg install` в реальном времени.

## 6. Анализатор нагрузки CPU и системы

- **Мониторинг CPU:** общая загрузка в реальном времени, разбивка по ядрам, показатели Load Average.
- **Память и Swap:** точные данные об использованной и свободной памяти, буферах и кэше.
- **Диски:** список примонтированных разделов и подключенных USB-накопителей.
- **Таблица процессов:** просмотр активных процессов роутера с сортировкой по нагрузке и кнопкой принудительного завершения (`Kill`).

## 7. Резервное копирование и восстановление

- **Бэкап списка пакетов:** экспорт текстового списка установленных программ для быстрой пакетной установки на новом роутере.
- **Полный архив настроек:** упаковка всей директории `/opt/etc/` в компактный архив `.tar.gz` с возможностью скачивания на компьютер или восстановления прямо на роутере.
