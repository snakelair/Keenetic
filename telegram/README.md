4. 🚀 **[`release_post_v1.0.28.md`](file:///c:/Projects%20My/SmartUtils/telegram/release_post_v1.0.28.md)** — Готовый пост-анонс текущего релиза v1.0.28.
5. 🛠 **[`installation_guide.md`](file:///c:/Projects%20My/SmartUtils/telegram/installation_guide.md)** — Шпаргалка по однострочным командам установки и управлению сервисами.
