### Текст поста для Telegram:

🎉 **Релиз Smart-Utils v1.0.28: Интерактивный установщик и проверка API!**

Встречайте масштабное обновление скрипта установки и веб-панели управления для роутеров Keenetic.

### 🌟 Что нового в версии v1.0.28:

🔹 **Интерактивный выбор порта при установке**:
• Установщик `install.sh` теперь аккуратно запрашивает желаемый порт веб-панели (по умолчанию `8090`), автоматически подтягивая ранее сохраненный порт из конфигурации роутера.
• Выбранный порт мгновенно сохраняется в `/opt/etc/smart-utils/config.json`.

🔹 **Синхронный запуск и валидация через реальный API**:
• После установки скрипт синхронно перезапускает службу и выполняет прямой запрос к `/api/status`.
• В консоль выводится точное подтверждение готовности, версия и определенная модель роутера (например, `Giga (KN-1011)`).

🔹 **Новый интерфейс консоли установщика**:
• Красивая ANSI-цветовая разметка статусов `[OK]`, `[ERROR]`, ссылок и разделителей.
• Полная очистка кеша списков OPKG для предотвращения ошибок с несовпадением контрольных сумм.
• Безопасная работа с терминалом (TTY) без лишних системных сообщений.

🔹 **Динамический список изменений (Changelog)**:
• Модальное окно обновлений в веб-панели всегда загружает актуальный список изменений напрямую из репозитория GitHub.

---

### 📥 Как обновиться или установить с нуля:

**Вариант 1 (из веб-панели Smart-Utils):**
Просто откройте веб-интерфейс, нажмите на бейдж версии `v...` в шапке и выберите **«Обновить сейчас»**.

**Вариант 2 (через терминал роутера):**
```bash
curl -sSL "https://raw.githubusercontent.com/snakelair/Keenetic/main/install.sh?_v=$(date +%s)" | sh -s smart-utils
```
