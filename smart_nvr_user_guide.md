## 1. Введение и архитектура

**SmartNVR** решает ключевую проблему владельцев систем видеонаблюдения: необходимость безопасного и легковесного просмотра камер из любой точки мира через домашний роутер Keenetic без необходимости проброса десятков портов и без использования устаревших браузерных плагинов (ActiveX, VideoPlayTool).

### Схема взаимодействия:
```
[ Клиент извне ]  ──>  (Интернет / KeenDNS / VPN)
                             │
                             ▼
                 [ Keenetic Роутер :8006 ]  <── (Шлюз SmartNVR)
                             │
        ┌────────────────────┼────────────────────┐
        ▼                    ▼                    ▼
[ Hiseeu NVR 4CH ]   [ iCSee Камера 1 ]   [ iCSee Камера 2 ]
  (172.16.1.107)       (172.16.1.44)        (172.16.1.114)
```

Роутер принимает входящие HTTP-запросы на порту **`8006`**, забирает видеопотоки и файлы архива с устройств во внутренней сети и проксирует их в браузер клиента.

## 2. Установка и запуск на роутере Keenetic

### Требования:
* Роутер Keenetic с установленным накопителем (USB-флешка, HDD или встроенное хранилище) и развернутой средой **Entware** (`/opt`).

### 1-Click установка через SSH:
Подключитесь к роутеру по SSH (порт 222 или 22) и выполните:
```bash
curl -sSL https://raw.githubusercontent.com/snakelair/Keenetic/main/install.sh | sh -s smart-nvr
```

### Развертывание с компьютера разработчика:
Запустите скрипт `deploy_to_router.bat` из папки проекта. Скрипт:
1. Запросит IP роутера (по умолчанию `172.16.1.1`).
2. Скомпилирует свежий бинарник `smart-nvr-linux-mipsle` (или `armv7`/`arm64`).
3. Загрузит бинарник и службу `/opt/etc/init.d/S99smart-nvr`.
4. Запустит сервис.

Веб-панель доступна по адресу: **`http://172.16.1.1:8006`**

## 3. Внешний доступ (KeenDNS / WAN / VPN)

Для доступа к SmartNVR через интернет настройте в веб-конфигураторе KeeneticOS:

1. **Через доменное имя KeenDNS (4-й уровень):**
   * Перейдите в *Сетевые правила* → *Доменное имя*.
   * В разделе *Настройка переадресации*:
     * Имя: `nvr`
     * Протокол: `HTTP`
     * Доменное имя: `nvr.ваш-роутер.keenetic.link`
     * Устройство: *Этот интернет-центр*
     * Порт назначения: **`8006`**
2. **Через VPN (WireGuard / Smart-VPN / Keenetic VPN):**
   * Подключите смартфон или ноутбук к домашней VPN-сети роутера.
   * Откройте адрес `http://172.16.1.1:8006`.

## 4. Поиск и добавление камер и NVR

Вкладка **«Поиск устройств»** позволяет найти все совместимые устройства в локальной сети:

1. Выберите подсеть (автоматически определяется `172.16.1.0/24`).
2. Нажмите кнопку **«Сканировать сеть»**.
3. Сканер опросит порты `34567` (NetSDK Sofia), `554` (RTSP) и `8899` (ONVIF).
4. В найденных карточках отобразится модель оборудования (например, `NBD89S08S-KL` или `X6E-WEQ`), серийный номер и количество каналов.
5. Нажмите **«+ Добавить в SmartNVR»** — откроется форма добавления с предзаполненными параметрами.

## 5. Просмотр видео в реальном времени (Live)

На вкладке **«Камеры (Live)»**:
* **Переключение сеток:** кнопки `1×1`, `2×2`, `3×3` адаптируют отображение под размер экрана.
* **Качество потока:**
  * **SD (Субпоток):** рекомендуется при просмотре через мобильный интернет 3G/4G для экономии трафика и мгновенного открытия.
  * **HD (Основной):** максимальная детализация Full HD / 4K.
* **Снимок кадра:** иконка фотоаппарата мгновенно сохраняет текущий кадр в формате `.jpg` на ваше устройство.
* **Полноэкранный режим:** открывает выбранную камеру на весь экран монитора или смартфона.

## 6. Работа с архивом записей (Playback)

SmartNVR позволяет просматривать записи с жесткого диска NVR без использования специализированных программ:

1. Откройте вкладку **«Архив (Записи)»**.
2. В верхней панели выберите:
   * **Устройство:** например, `Hiseeu 4CH NVR`.
   * **Канал:** `Канал 1`, `Канал 2` и т.д.
   * **Дату архива:** выберите день в календаре.
3. Нажмите **«Загрузить записи»**.
4. Сервер опросит регистратор через протокол Sofia (`OPFileQuery`) и отобразит:
   * **24-часовую интерактивную шкалу:** зеленые полосы отображают периоды, когда велась запись.
   * **Список отрезков:** время начала/конца, длительность и размер файла.
5. Нажмите **«Воспроизвести»** или кликните по шкале времени для запуска видеоплеера.

## 7. PTZ-управление поворотными камерами iCSee

Для поворотных камер (например, `172.16.1.44` и `172.16.1.114`):
1. В карточке камеры в режиме Live нажмите иконку джойстика PTZ.
2. В появившемся окне доступны:
   * Стрелки поворота: **Вверх**, **Вниз**, **Влево**, **Вправо**.
   * Управление оптическим/цифровым зумом: **Zoom +** / **Zoom -**.
3. Команды транслируются через шлюз роутера по протоколу `OPPTZControl` напрямую в камеру.

## 8. Управление службой Entware и диагностика

### Команды управления на роутере:
```bash
# Проверить статус службы
/opt/etc/init.d/S99smart-nvr status

# Перезапустить службу
/opt/etc/init.d/S99smart-nvr restart

# Остановить службу
/opt/etc/init.d/S99smart-nvr stop

# Запустить службу
/opt/etc/init.d/S99smart-nvr start
```

### Расположение файлов:
* Исполняемый файл: `/opt/bin/smart-nvr`
* Конфигурация: `/opt/etc/smart-nvr/config.json`
* Скрипт автозапуска: `/opt/etc/init.d/S99smart-nvr`
* Журнал в оперативной памяти (RAM): `/tmp/smart-nvr.log`

## 9. Особенности работы с Hikvision и окружением Entware

### Пакеты FFmpeg в Entware (устранение ошибки 127)
Для корректной работы автономной записи NVR требуются пакеты `ffmpeg` и `libffmpeg`:
```bash
opkg update
opkg install ffmpeg libffmpeg
```
> **Важно:** Пакет `libffmpeg` содержит разделяемые библиотеки кодеков и устройств ввода/вывода (включая `libavdevice.so.63`). Без него бинарный файл `ffmpeg` не может запуститься и завершается с кодом **127**. SmartNVR явно логирует код возврата и выводит подробную подсказку в веб-интерфейсе.

### Камеры Hikvision: 401 ошибка авторизации RTSP и режим «Всегда Basic»
В современных прошивках Hikvision (например, V5.8.42 на серии DS-2CD1143G2) в 401-челлендже RTSP отдаются сразу несколько схем: `MD5`, `SHA256` и `MD5/SHA256`. Встроенный демультиплексор FFmpeg спотыкается о составную схему `MD5/SHA256`, не может вычислить хэш и молча прерывает авторизацию с кодом 401.

**Решение в SmartNVR:**
1. Откройте карточку камеры в настройках SmartNVR.
2. В поле **«RTSP-авторизация»** выберите **«Всегда Basic (рекомендуется для Hikvision)»**.
3. SmartNVR автоматически смаршрутизирует поток через встроенный RTSP-прокси, авторизуется на камере по надежной схеме Basic и предоставит ffmpeg готовый локальный поток.

### Детекция движения и события Hikvision (ISAPI alertStream)
Камеры Hikvision с аналитикой VMD 2.0 / AcuSense не отдают реальные события движения по протоколу ONVIF PullPoint (передавая лишь периодический heartbeat).
* SmartNVR автоматически подключается к шине событий камеры: `GET /ISAPI/Event/notification/alertStream` с Basic-авторизацией.
* События движения (`VMD`), пересечения линий (`linedetection`) и саботажа (`shelteralarm`) регистрируются мгновенно и без задержек.
* При использовании ONVIF для других камер SmartNVR поддерживает постоянную подписку (`Renew` каждые 5 минут вместо пересоздания), не исчерпывая лимит слотов камеры.

### Ограничения python3-light в Entware
При разработке собственных интеграций обратите внимание:
* Пакет `python3-light` в Entware собран без модуля `unicodedata`, из-за чего модуль `idna` падает с ошибкой `EAI_NONAME` при разрешении доменных имен.
* Если требуются Python-скрипты, установите полный пакет `python3` либо обращайтесь к устройствам по IPv4-адресам.
* Для работы SmartNVR сторонние скрипты и мосты не требуются — весь функционал реализован нативно в Go.
